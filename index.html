  • Safe by default

    No unsafe code in the default build - the workspace denies unsafe_code at the lint level rather than relying on review.

  • YAML 1.2.2

    Validated against the upstream yaml-test-suite conformance corpus, vendored as a submodule so results are reproducible.

    Benchmarked against other Rust YAML engines with recorded baselines rather than claimed numbers.
